# Five Star: CRM Design Hub

A working surface for designing the HubSpot setup, published for comment and not as a finished report. The hub is behind a password.

It models the organisation first, then the CRM design that mirrors it, and keeps the audit behind that as evidence.

## Reviewing it

Open the hub and use the Comments button, or add `?review=1` to the address. Hover any text and click the + to leave a comment. Comments stay in your own browser: they are not shared between reviewers and are not sent anywhere.

Every screen, tab and open item has its own address, so Copy link gives a link straight to what you are looking at.

## Status and accuracy

This is a draft built to be argued with. Items marked Recommended are proposals, and items marked Changed since were overtaken after the audit. If something here is wrong, the review mode is the fastest way to say so.
