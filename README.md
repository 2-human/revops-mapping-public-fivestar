# Five Star: CRM Design Hub

A working surface for designing the HubSpot setup, published for comment and not as a finished report. Each person signs in with their own work email: the hub sends a one-time link, and only accounts on the list can open it.

It models the organisation first, then the CRM design that mirrors it, and keeps the audit behind that as evidence.

## Reviewing it

Open the hub and use the Feedback button, or add `?review=1` to the address. The Feedback Drawer has two parts: QA, where the North Star team leaves comments on any screen or open item, and Q&A, where the client answers the interview questions, with files if needed. Answers can also be given on the Answer tab of each question. Everything is shared between the people signed in.

Every screen, tab and open item has its own address, so Copy link gives a link straight to what you are looking at, and a link still opens on that screen after signing in.

## Status and accuracy

This is a draft built to be argued with. Items marked Recommended are proposals, and items marked Changed since were overtaken after the audit. If something here is wrong, the review mode is the fastest way to say so.
